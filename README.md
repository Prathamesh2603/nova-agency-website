# NOVA Studio — Digital Agency Website

A modern, responsive digital agency website built with React and Tailwind CSS. NOVA features a clean editorial aesthetic, bold typography, project showcases, interactive testimonials, and a strong contact section.

🌐 Live Demo: https://nova-agency-alpha.vercel.app/

## ✨ Features

- **Responsive design** — layouts for mobile, tablet, and desktop.
- **Modern hero section** — bold typography and clear calls to action.
- **Services section** — highlights the agency's core offerings.
- **Project showcase** — displays selected projects in a responsive grid.
- **About section** — communicates the agency's values and approach.
- **Process section** — presents the project workflow from discovery to launch.
- **Interactive testimonials** — navigate between client-story examples.
- **Mobile navigation** — collapsible menu for smaller screens.
- **Contact CTA** — encourages visitors to start a project.
- **Custom branding** — NOVA logo, favicon, and consistent visual identity.

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Lucide React
- Google Fonts — Space Grotesk and DM Sans

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed on your computer.
- Git installed if you want to clone or push the project to GitHub.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Prathamesh2603/nova-agency-website
   ```

2. Navigate to the project folder:

   ```bash
   cd nova-agency
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🎨 Design Direction

NOVA uses a minimal, editorial-inspired design system:

- **Background:** Warm off-white
- **Typography:** Space Grotesk for headings and DM Sans for body text
- **Accent:** Lime green
- **Layout:** Spacious sections, strong typography, and responsive grids
- **Interactions:** Hover effects, mobile menu, and testimonial navigation
